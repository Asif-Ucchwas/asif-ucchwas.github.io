TrackLoop: vehicle path tracking

Four path-tracking controllers on a car model, benchmarked the same way as ControlLoop-RT: Pure Pursuit, Stanley, LQR and linear MPC. Every number on this page comes from a file in the repo, and a test fails if the README drifts from the data.
