Projects

What I've built

A*-guided adaptive-corridor RRT* with Kalman filter localization

Real-time ground-vehicle navigation, deployed as live ROS2 nodes. Read the thesis

  • A* supplies a global guide; RRT* refines a smooth path only inside an adaptive corridor around it.
  • 98% vs 60% success and 5.87% shorter paths than RRT*; 90%+ at high density where RRT* fell to 40%.
  • Kalman filter odometry fusion cut localization error by 44.1%. Ships as a reproducible Docker demo.
C++PythonROS2 JazzyNav2TF2AMCLGazeboDocker

Percept-Nav

Multi-sensor perception feeding real-time replanning.

  • OpenCV detection fused with LiDAR, time-synchronized, written into a custom C++ Nav2 costmap plugin.
  • 8 moving obstacles at 4× speed, zero collisions; gtest against a real Nav2 layered costmap.
C++/pluginlibOpenCVSLAM ToolboxNav2gtest
